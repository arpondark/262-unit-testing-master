## B) Defects list

No confirmed defect was found in `Booking` against the documented behavior tested here. The documented time validation and wallet transfers belong to `ParkingSystem.book`, `ParkingSystem.completeBooking`, and `ParkingSystem.cancelBooking`, so they are outside this Booking only report.

Observation: `Booking.completeBooking()` and `Booking.cancelBooking()` allow a later call to change one terminal status into the other. The supplied documentation does not specify whether this must be rejected, so it is not listed as a confirmed defect. If terminal states are intended to be final, guard these methods against transitions from `COMPLETED` or `CANCELLED`.
